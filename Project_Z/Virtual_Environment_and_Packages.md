# 03. Virtual Environment / pip / Packages

この章では、Pythonの仮想環境を作成し、プロジェクトごとに必要なPackageを管理する方法を学ぶ。

最終的には、プロジェクト内に以下のような環境を作る。

```text
my-project/
├── .venv/
├── Project_A/
├── Project_B/
├── Project_C/
├── Project_Z/
├── README.md
├── .gitignore
└── requirements.txt
```

## 1. Virtual Environment

`.venv`とは何か、なぜ仮想環境を作るのかを理解する。

## 2. pip

Python Packageをインストール・管理するための `pip` について学ぶ。

## 3. Packages

NumPy、Matplotlib、JupyterなどのPackageと、そのDependenciesについて理解する。

## 4. requirements.txt

プロジェクトに必要なPackageを記録し、別の環境でも同じ環境を再構築できるようにする。

## 5. `.venv` の中身

`.venv` の内部には何が入っているのか、PythonやPackageがどこに存在するのかを確認する。
