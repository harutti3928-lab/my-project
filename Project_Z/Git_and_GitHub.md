# 04. Git and GitHub

この章では、Gitを使ってプロジェクトの変更履歴を管理し、GitHubと連携してコードを保存・共有する方法を学ぶ。

最終的には、

```text
Working Directory
       ↓ git add
Staging Area
       ↓ git commit
Local Repository
       ↓ git push
GitHub
```

というGitの基本的な流れを理解する。

## 1. Git Repository

`git init` によって作られる `.git` とは何なのかを理解する。

## 2. `.gitignore`

GitHubに管理させないファイル・フォルダを指定する。

## 3. VS CodeとGit

VS CodeのSource ControlからGitを操作する方法を確認する。

## 4. Commit / Push / Pull

変更をGitに記録し、GitHubと同期する一連の流れを学ぶ。

## 5. コマンドとVS Codeの対応

VS Code上の操作が、Gitコマンドではどのように対応しているのかを整理する。
